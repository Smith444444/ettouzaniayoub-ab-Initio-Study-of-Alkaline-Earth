# Ab Initio Study of Alkaline Earth Thallium Chloride Perovskites

## Description
This repository contains the input files and data scripts for the DFT study of **ATlCl3 (A = Mg, Ca, Sr, Ba)** perovskites using **Quantum ESPRESSO**.

## Project Structure
- **/MgTlCl3**: Input files for SCF, NSCF, and Band structure calculations for MgTlCl3.
- **/Scripts**: Python scripts used for plotting Band Structures and DOS.
- **/Data**: Extracted data for Light Yield calculations.

## Methodology
- **Code**: Quantum ESPRESSO (v6.8)
- **Functional**: GGA-PBE
- **Cutoff Energy**: 884 eV
- **K-points**: 5x5x5 (SCF), 15x15x15 (NSCF)
